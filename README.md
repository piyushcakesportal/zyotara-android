# Zyotara

Early Android MVP for a personal AI astrology guide.

Package: `com.darkbyte.zyotara`

Included:
- Birth profile
- Life-score dashboard
- Daily action plan
- Demo question-and-answer assistant
- Local profile storage
- GitHub Actions APK build

The scores and guidance are placeholders. Production requires a real astrology calculation engine, secure backend, privacy disclosures, and non-guaranteed safety wording.
